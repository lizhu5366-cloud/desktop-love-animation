# 桌面动画

在 Windows 桌面上播放猫咪爱心动画，适合表白、纪念日、惊喜庆祝。

## 效果

- 一群猫咪 GIF 沿爱心曲线拼成一颗心
- 停留几秒后清空
- 猫咪 GIF 铺满整个屏幕
- 配背景音乐

## 使用方式

在豆包对话框里输入：

> 帮我下载并部署GitHub上的lizhu5366-cloud/desktop-love-animation到D盘，这是一个桌面浪漫动画项目，帮我安装依赖并运行起来

## 退出方式

按键盘 `Esc` 键全部关闭。

## 支持系统

- Windows 10/11
- macOS（需自行安装 Python3 + Pillow）

## 技术栈

- Python 3
- tkinter
- Pillow
